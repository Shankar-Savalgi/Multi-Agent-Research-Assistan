# Scholar Agents

**A multi-agent AI research assistant that turns one problem statement into a cited literature review, where every citation points to a real paper.**

Four agents (Planner, Retriever, Verifier & Analyst, Writer) search real scholarly indexes, check the evidence, compare solutions, expose research gaps and draft a report. The model never invents a source: it is only shown papers that were actually retrieved, and the reference list is built by the application itself.

## Why this project

Literature research is the slowest part of academic work. Searching, deduplicating, ranking and formatting citations takes far longer than the thinking itself. Language models can speed this up, but they often produce plausible-looking references to papers that do not exist.

Scholar Agents takes the opposite route:

- Retrieval is done by real APIs against real scholarly indexes.
- The language model only filters, compares and writes about the papers it is given.
- The reference list is generated by the app, not the model.

## How it works

```
 Problem statement
        |
        v
 [ 1 Planner ]            Claude   -> 3-4 search queries + 3-5 sub-questions
        |
        v
 [ 2 Retriever ]          OpenAlex -> candidate papers (Crossref fallback)
        |                           -> deduplicated, ranked, numbered [1..n]
        v
 [ 3 Verifier & Analyst ] Claude   -> relevant ids, comparison table, gaps
        |
        v
 [ 4 Writer ]             Claude   -> cited literature review (Markdown)
        |
        v
 Report + reference list  -> download .md
```

## Agents

| Agent | Input | Output | Engine |
|---|---|---|---|
| **Planner** | Problem statement (max 2000 characters) | JSON: 3-4 keyword queries, 3-5 sub-questions | Claude |
| **Retriever** | The generated queries | Up to 14 numbered papers (title, authors, year, venue, citation count, link, abstract) | OpenAlex, then Crossref |
| **Verifier & Analyst** | Problem + full retrieved corpus | JSON: relevant ids, per-paper comparison with evidence grade, research gaps with citations | Claude |
| **Writer** | Problem + analysis + relevant papers | Markdown review: Summary, Landscape of Approaches, Comparative Findings, Research Gaps, Recommended Directions | Claude |

## Features

- Decomposes a free-text problem into effective academic search queries.
- Retrieves real, dated papers from OpenAlex (250M+ works) with automatic Crossref fallback.
- Deduplicates by normalised title and ranks by citation count.
- Filters genuinely relevant papers from keyword-only matches.
- Compares approach, strength and limitation, and grades evidence as strong, moderate or weak.
- Surfaces research gaps with the sources that justify each one.
- Generates a five-section review where every claim carries a bracketed citation id.
- Shows live agent progress and exports the report as Markdown with its reference list.
- Each agent is a server function, so prompts and API keys never reach the browser.

## Getting started

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>

# 2. Install dependencies
npm install        # or: bun install

# 3. Start the dev server
npm run dev

# 4. Run tests
npm run test

# 5. Production build
npm run build
```

> The reasoning engine is reached through the Lovable AI Gateway, so the workspace needs AI credits available. No separate Claude account or API key has to be configured by hand.

### Usage

1. Type a problem statement on the home page and press **Run research**.
2. Watch the four agent cards progress.
3. Review the research plan, references, comparison table and research gaps.
4. Read the generated report and click **Download .md** to save it with the full reference list.

## 3D showcase website

This repository also includes a presentation site for the project: a single, self-contained HTML file with a scroll-driven 3D scene.

- A team introduction, then a camera flight through the four agents.
- Papers flow along a glowing pipeline. At the Verifier, relevant papers turn teal and continue while the rest fall away.
- Interactive citation demo, animated results, scrolling tech banner and a "Thank You" finale.
- **AI voice guide:** press *Hear the AI guide* and a narrator explains the project section by section, with live captions. It uses the browser's built-in Web Speech API.

**Run it locally:** open `scholar-agents.html` in a modern browser (Chrome, Edge or Safari). No build step is required. It loads three.js (r128) and Google Fonts from CDNs, so an internet connection is needed.

> If the voice guide is silent, open the file directly in its own browser tab, turn the volume up and switch off silent mode. Captions play either way.

## Citation traceability

Traceability is a property of the data flow, not of the prompt.

1. The Retriever numbers each paper as it enters the pool.
2. The Verifier and Writer are given only those numbers.
3. A bracketed id such as `[7]` resolves to a reference entry built from retrieved records: authors, year, venue and a live link.
4. A claim with no id, or an id with no retrieved paper behind it, is visible at a glance.
